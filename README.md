# Gambit Drill feedback

This public repository is only for feedback on Gambit Drill. The app source
and private planning notes live elsewhere.

Use **Discussions** for impressions and questions. Use the issue forms for
bugs and repertoire corrections. Please do not post personal game archives,
private Chess.com usernames, Lichess tokens, or other account details. A
screenshot is optional; crop it to the relevant app screen first.

The app is free for personal use, works offline after its first load, and
does not require an account. Chess.com and Lichess are contacted only when
you choose those features. See the app's privacy and licence notices for
details.

## Repository setup

Create a separate public repository named `gambit-drill-feedback` and copy
only this template's README, `.github/ISSUE_TEMPLATE/`, and
`PINNED_DISCUSSION.md` into it. Keep source code and internal research out.
Enable Discussions; use the General or Feedback category; pin the text in
`PINNED_DISCUSSION.md`. Create the `bug` and `repertoire` labels if desired.
