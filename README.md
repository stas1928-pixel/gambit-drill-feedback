# Gambit Drill feedback

[Try Gambit Drill](https://cheka-56c.pages.dev/), a chess opening trainer for
the Scotch Gambit and Elephant Gambit.

This public repository is for feedback. The app source and private planning
notes live in a separate private repository.

Use [Discussions](https://github.com/stas1928-pixel/gambit-drill-feedback/discussions)
for impressions and questions. Use the issue forms for bugs and repertoire
corrections. Please do not post private game archives, Chess.com usernames,
Lichess tokens, or other account details. Screenshots are optional; crop them
to the relevant app screen first.

The app is free for personal use, works offline after its first load, and does
not require an account. Chess.com and Lichess are contacted only when you
choose those features. See the app's privacy and licence notices in Settings.
